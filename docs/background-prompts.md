# 兩張舞台背景提示詞

生成時附上 `assets/backgrounds/Start_dark.PNG` 作為材質、透視與畫風參考。
兩張皆使用橫式 **3:2、1536 × 1024**，與目前密室背景一致。畫面是供真人
演員站在前方的舞台投影，中央與下方要保持簡潔。辦公室屬於過去的回憶，
應呈現正常企業辦公環境。

## 1. 記憶室

建議存放：`assets/backgrounds/memory-room.png`

```text
請以附上的密室圖片作為視覺參考，生成同一劇場世界觀中的「記憶室」舞台投影背景。橫式 3:2，1536 × 1024。寫實電影場景，正面、平視、固定廣角鏡頭，垂直線筆直，透視與參考圖一致。房間空無一人，具有冷灰色金屬牆板、簡潔的天花板與深灰地磚，低亮度冰藍色燈帶與柔和頂光，安靜、封閉、帶有被監視的壓迫感，但地面與道具仍清楚可辨。畫面左後方靠牆放一張小巧的深色桌子，桌上只有一個直立的小相框，柔和聚光照亮相框；相框內部留白，方便之後加入照片。其餘家具極少，中央與下半部保留大面積空地，讓四位真人演員站在投影前方時畫面仍乾淨。降低地面反光與細碎紋理，不要新增巨大螢幕、倒數計時器、控制介面或機器人。不要人物、剪影、可讀文字、房號、標誌、浮水印；不要魚眼變形、插畫風或過度科幻裝飾。
```

## 2. 辦公室回憶

建議存放：`assets/backgrounds/office-memory.png`

```text
生成一張供真人演員演出的「公司辦公室回憶」舞台投影背景。橫式 3:2，1536 × 1024。採用附上密室圖片相同的寫實電影質感、正面平視固定廣角鏡頭、筆直垂直線與相近透視。場景是一間正常的現代企業辦公室，簡潔的淺灰牆面、玻璃隔間與深灰地板，柔和的中性日光搭配略暖的室內燈，氣氛克制、嚴肅，適合演出同事間的衝突。畫面左後方靠牆是一張簡單辦公桌，桌面只有幾疊整齊文件、文件夾與一盞桌燈；後景可以有低矮文件櫃與少量辦公用品。中央和右側保持開闊，中央與下半部不放大型家具，保留四位真人演員的表演空間。背景細節適量、光線均勻、地面低反光。不要人物、剪影、可讀文件文字、公司招牌、標誌、浮水印；不要密室房號、倒數計時器、機器人、霓虹科幻設備、魚眼變形或插畫風。
```

相框照片與題字另外加入，避免生成圖片寫錯劇情文字。其餘語音與音效待之後
整理，不包含在本次背景製作中。
