# AI 對準電視內框

第一場 AI 固定在 `IMG_0165.png` 的電視正中央，依波形與主要輪廓
可容納的最大尺寸繪製。背景 cover 裁切、全螢幕及步驟檢視縮放時，
AI 都跟隨電視；光暈與粒子限制在黑色內框裡。

`opening-config.js` 的 `roomScreen` 使用原圖像素：

| 項目 | 數值 |
| --- | --- |
| 原圖尺寸 | 1536 × 1024 |
| 內框左上 | x＝552、y＝310 |
| 內框尺寸 | 寬＝430、高＝195 |
| 正中央 | x＝767、y＝407.5 |
| 內距 | 2 像素，隨背景等比例縮放 |

圖形維持比例，不為填滿橫向電視而拉伸。歡迎語音期間只在內框內小幅
放大，語音播完縮回；中心一直固定在電視上。碼錶及沒有電視的記憶室
沿用原本的 Y＝40%、大小＝37%。若更換第一場背景，須重新量出新電視內框。

  最大頻譜輸入下，波形、外圈、粒子及發光都未超出電視。
- 1920×1080、1440×900、390×844，全頁與步驟檢視皆涵蓋。
- HTTPS 預覽另確認開始前影音時間為 0；開始後影片自然結束，
  按鍵全部隱藏，AI 出現在電視中央。
