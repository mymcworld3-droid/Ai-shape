# 手動播放幕後花絮：影片預留位置

第四幕結束後，**最終全暗** 是獨立的步驟（場景模式第 31 步）。畫面保持全黑，不會在等待時自動開播。操作員必須**再按一次下一步**（空白鍵、右方向鍵、投影畫面點擊、或遠端遙控器）才進入 **播放幕後花絮**（場景模式第 32 步）。

## 影片檔案名稱與位置

**檔名：** `behind-the-scenes.mp4`

**GitHub 專案內相對位置：** `assets/videos/behind-the-scenes.mp4`

例如：`Ai-shape/assets/videos/behind-the-scenes.mp4`。請上傳 MP4 格式，建議 H.264 影像、AAC 音訊，16:9。上傳到 GitHub 後部署至 Render 才會在網站上生效。

目前僅有預留程式碼，沒有新增實際影片。影片未上傳或無法讀取時，花絮步驟保持全黑，不阻擋演出開始，不影響既有背景音樂、字幕與其他媒體。影片只有在進入花絮步驟時才嘗試載入／播放。按「上一步」會停止影片並返回最終全暗；再進入花絮會由頭重新播放。影片結束不自動切換下一步。花絮影片的聲音使用現有「音效」音量通道（2 / W 與遙控拉桿）。

逐句字幕模式同樣有對應的最後一個**第 380 步**（原始 0–379 不變）。
