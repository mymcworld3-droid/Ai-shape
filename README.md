## 多裝置線上操控

使用 Node.js 22 以上執行 `npm ci` 和 `npm start`。部署時請使用支援 WebSocket 的 Node 網站服務（例如 Render Web Service），所有裝置開啟**同一個網站網址**，不需在同一個 Wi-Fi 內。

1. **播放裝置**：開啟首頁、選好演出模式與步驟，按「開始」。這台裝置自動成為唯一的播放端，負責所有畫面、影片及音效。
2. **其他手機／電腦**：開啟同一個網站，點「操控頁面」，或直接開啟 `/remote.html`。不用配對；即使在播放前先進入操控頁面，也會等待播放端開始。
3. 任何已連線的操控端都能切換上／下一步、調整三組音量及切換音量顯示，也能按「☷ 步驟清單」搜尋、檢視並點選任意步驟直接跳轉。清單標記目前步驟，場景模式的名稱取自播放端原始清單，逐句字幕則使用相同劇本資料。所有操控端會收到最新進度，操控端本身不播放演出聲音或影片。
4. 跳轉時立即停止上一段語音、音效或影片，直接套用目的步驟的畫面與媒體，不逐一執行被略過的 cue。若跳進同一段錄音的中間台詞，原錄音會從頭播放（尚無逐句音訊時間碼）。主操控畫面維持不捲動，步驟清單另外以可搜尋的視窗顯示。
5. 播放端關閉、重新整理或斷線時，操控端暫停操作；另一台裝置按「開始」後可接手。暫時斷線會嘗試重新連線。

「配對」按鈕仍保留原有的專用配對網址功能，作為進階備用方案。公開操控頁面不使用密碼，**任何能開啟此網站的人都能操作正在播放的演出**，請只在可信任的團隊內分享網址。使用多個 Render 執行個體時應設定單一服務執行個體，讓所有 WebSocket 連到相同的記憶體內同步狀態；單純 GitHub Pages 或 `python -m http.server` 不支援線上操控。

### 遠端語音的自動重試

若播放裝置的瀏覽器暫時拒絕遠端指令觸發 AI 語音（`NotAllowedError`），系統會在原場景或原逐句字幕步驟自動重試最多兩次（約 450 ms、1,200 ms），不更換台詞、不重啟倒數；所有控制端會看到重試提示。播放成功後提示自動消失。

若連續失敗，僅在此時顯示播放裝置上的「啟用語音並重試」按鈕。瀏覽器的自動播放授權屬於安全限制，無法靠計時器或另一台裝置的點擊繞過，必要時仍須在播放裝置互動一次。

### 場景／字幕模式的提前提示、步驟控制與音訊電平

遠端原有「下一步預告」已改成「步驟前後預覽」，以**即將進入的下一步**為中心，顯示其**前兩步、目標步驟、後兩步**（最多五個連續操作步驟）。例如現在正演第 30 步、下一步為第 31 步時，預覽範圍就是 29–33 步。每行帶有真實步驟編號及角色／台詞，目前正在執行的步驟與接下來要切換的步驟分別醒目標示；演出開始或結尾若不足五步，僅顯示存在的步驟。內容隨投影端進度、上一／下一步、遠端跳轉及斷線重連同步更新。**場景模式**依實際場景 cue 與劇本原始段落顯示場景名稱及相應台詞；**逐句字幕模式**依 `SUBTITLE_SCRIPT.entries` 的合併字幕順序，一步對應一個真實操作步驟，純音效／畫面步驟則顯示該步驟說明，不將前後台詞錯當作同一步。手機版仍維持單畫面、不捲動的操控版面。

兩種模式也都保留上一步、下一步和「☷ 步驟清單」：可搜尋全部步驟、查看目前位置，直接點選跳至指定步驟。

三組音量以 **0–100% 滑桿**直接調整播放裝置的語音、音效、背景音樂；原有 1/Q、2/W、3/E 快捷鍵不受影響。每組滑桿下方另設即時電平表，顯示播放端音訊的實際 RMS 輸出強度（-60～0 dBFS，每秒約更新 8 次），靜音或未播放時顯示「靜音」。這是瀏覽器內音訊訊號的測量，**不是外接音響或麥克風的聲壓實測**。操控端只接收電平數字，不接收演出音訊。
